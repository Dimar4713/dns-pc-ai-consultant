# DNS PC AI Consultant

Пилотный AI-консультант по подбору совместимого компьютера и полного рабочего места на основе товарного среза DNS.ru.

Приложение подготовлено для прямого импорта в Replit через GitHub и использует OpenAI-совместимый API RouterAI.ru. Пользователь задаёт API-ключ и выбирает модель в настройках чата; параметры сохраняются в браузере.

## Возможности

- простой чат-интерфейс;
- приветствие и 2–4 уточняющих вопроса;
- персонализированная презентация сборки;
- проверка сокета, DDR4/DDR5, форм-фактора, BIOS, питания, размеров корпуса и охлаждения;
- подбор монитора под разрешение, частоту и класс видеокарты;
- подбор клавиатуры, мыши, гарнитуры, веб-камеры, Wi‑Fi/Bluetooth, звука и защиты питания;
- каталог моделей с характеристиками, ценами-ориентирами и ссылками на карточки DNS;
- локальный RAG-lite без внешней базы данных;
- маршрутизация запросов по категориям и синонимам: ОЗУ/RAM, экран/монитор, SSD/HDD, Wi‑Fi и другие;
- выбор модели RouterAI и ручной ввод model ID;
- сохранение API-ключа и модели после перезагрузки;
- семь smoke-тестов без расхода API-баланса.

## Импорт в Replit

1. В Replit выберите **Create App → Import from GitHub**.
2. Выберите репозиторий `Dimar4713/dns-pc-ai-consultant`.
3. Основная ветка: `dns-pc-ai-consultant`.
4. Replit установит зависимости командой `npm install`.
5. Запустите проект кнопкой **Run** или командой `npm start`.
6. В интерфейсе нажмите ⚙, введите API-ключ RouterAI и выберите модель.

API-ключ не добавляйте в GitHub. Для пилотного проекта он хранится только в `localStorage` браузера. Для публичного приложения предпочтительны Replit Secrets.

## Локальный запуск

```bash
npm install
npm start
```

По умолчанию сервер использует переменную `PORT` или порт `3000`.

## Проверка

```bash
npm test
```

Тест запускает локальный mock RouterAI и проверяет семь сценариев:

1. игровой ПК Full HD;
2. рабочая станция для монтажа 4K;
3. компактный офисный ПК;
4. отдельный подбор DDR5;
5. подбор игрового монитора 1440p;
6. Wi‑Fi/Bluetooth и периферия;
7. полный комплект рабочего места «под ключ».

## Структура

```text
server.js                    сервер Express, RouterAI и категорийный RAG
public/                      интерфейс чата
data/knowledge-base-01..05   базовые комплектующие, цены и сборки
data/knowledge-base-06.md    RAM DIMM/SO-DIMM, HDD, SATA SSD, NVMe
data/knowledge-base-07.md    мониторы и согласование с GPU
data/knowledge-base-08.md    периферия, Wi-Fi/Bluetooth, камеры и звук
data/knowledge-base-09.md    вентиляторы, ИБП, кабели и полный комплект
prompts/system-prompt.md     системная инструкция консультанта
docs/CATALOG_COVERAGE.md     аудит покрытия каталога
docs/REPLIT_TZ.md            техническое задание
docs/REPLIT_MASTER_PROMPT.md промпт для Replit Agent
docs/MODEL_SELECTION.md      выбор моделей RouterAI
scripts/smoke-test.js        автоматическая проверка
```

Сервер автоматически находит все `data/knowledge-base-*.md`, сортирует и объединяет их при запуске. Затем он определяет категории запроса по синонимам и передаёт модели обязательные правила совместимости вместе с наиболее подходящими разделами каталога.

## Ограничения

Это репрезентативный пилотный срез, а не полная зеркальная копия DNS. Цены и наличие зависят от региона, акции и даты. Если DNS не показывает единую цену без выбора города, в базе указано «проверить в выбранном регионе». Консультант не должен выдумывать цену, наличие, версию BIOS, физическую совместимость или комплектность кабелей.
