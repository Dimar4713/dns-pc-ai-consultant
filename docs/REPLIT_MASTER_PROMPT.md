# Готовый промпт для Replit Agent

Создай и запусти Node.js 20 веб-приложение «AI-консультант по сборке ПК» в соответствии с приложенным файлом `docs/REPLIT_TZ.md`.

Используй существующую структуру проекта и не заменяй её React/Vite без необходимости. Backend должен быть на Express, frontend — чистые HTML/CSS/JavaScript. Главный экран должен оставаться простым чатом. Кнопка настроек открывает модальное окно RouterAI.

Обязательные условия:

1. Загружай и объединяй в алфавитном порядке все файлы `data/knowledge-base-*.md`.
2. Загружай системный промпт из `prompts/system-prompt.md`.
3. Перед каждым запросом дели объединённую базу по Markdown-заголовкам, ранжируй разделы по словам последних сообщений и добавляй наиболее релевантные фрагменты в системное сообщение. Всегда включай правила совместимости и ограничения честности.
4. Используй RouterAI OpenAI-compatible endpoint `https://routerai.ru/api/v1/chat/completions` с Bearer-авторизацией.
5. В настройках должны быть API-ключ и выбор модели. Сохраняй оба значения в localStorage, чтобы они переживали перезагрузку.
6. Модели по умолчанию: DeepSeek V4 Pro, Qwen3.5 35B A3B, GPT-5.6 Luna, Claude Sonnet 5; разреши ручной ID.
7. Не логируй API-ключ.
8. При старте покажи приветствие и 3 группы уточняющих вопросов.
9. Консультант должен сначала собрать потребности, затем выдать персональную презентацию, альтернативу и отдельную проверку совместимости.
10. Для рекомендованных моделей из базы показывай цену-ориентир и кликабельную ссылку DNS.
11. Не выдумывай цены, наличие, BIOS и физические размеры.
12. Добавь понятную обработку ошибок API.
13. Сохрани мобильную адаптивность.
14. Запусти `npm test`, затем `npm start`; исправь все найденные ошибки.
15. Не удаляй файлы документации и базу знаний.

Критерий завершения: приложение открывается в Replit Preview, настройки сохраняются после reload, mock smoke test проходит, а реальный запрос работает после ввода действующего RouterAI API-ключа.
