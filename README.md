# DNS PC AI Consultant

Учебный AI-консультант по подбору совместимых комплектующих для сборки компьютера на основе товарного среза DNS.ru.

Приложение предназначено для импорта в Replit через GitHub и использует OpenAI-совместимый API RouterAI.ru. Пользователь задаёт API-ключ и выбирает модель в настройках чата; параметры сохраняются в браузере.

## Возможности

- чат-интерфейс без лишних экранов;
- приветствие и 2–4 уточняющих вопроса;
- персонализированная подборка комплектующих;
- проверка сокета, типа памяти, форм-фактора, BIOS, питания, размеров корпуса и охлаждения;
- цены-ориентиры и ссылки на карточки DNS;
- локальная база знаний в Markdown и TXT;
- выбор модели RouterAI;
- сохранение настроек после перезагрузки;
- три smoke-теста без расхода API-баланса.

## Запуск в Replit

1. В Replit выберите **Create Repl → Import from GitHub**.
2. Укажите репозиторий `Dimar4713/dns-pc-ai-consultant`.
3. Replit установит зависимости командой `npm install`.
4. Запустите проект командой `npm start`.
5. В интерфейсе нажмите ⚙, введите ключ RouterAI и выберите модель.

## Локальный запуск

```bash
npm install
npm start
```

Откройте адрес, который выведет сервер. По умолчанию используется порт из переменной `PORT` или `3000`.

## Проверка

```bash
npm test
```

## Структура

- `server.js` — сервер и обращение к RouterAI;
- `public/` — интерфейс чата;
- `data/knowledge-base.md` — рабочая база знаний;
- `prompts/system-prompt.md` — системный промпт;
- `docs/` — ТЗ, мастер-промпт, выбор моделей и тестовые диалоги;
- русскоязычные копии материалов в корне — для сдачи домашнего задания.

## Важное ограничение

Цены и наличие на DNS зависят от региона и меняются. Консультант обязан показывать дату ценового среза и не должен выдумывать цену, наличие или совместимость, если этих данных нет в базе.
