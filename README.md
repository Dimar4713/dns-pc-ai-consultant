# DNS PC AI Consultant

Учебный AI-консультант по подбору совместимых комплектующих для сборки компьютера на основе товарного среза DNS.ru.

Приложение подготовлено для прямого импорта в Replit через GitHub и использует OpenAI-совместимый API RouterAI.ru. Пользователь задаёт API-ключ и выбирает модель в настройках чата; параметры сохраняются в браузере.

## Возможности

- простой чат-интерфейс;
- приветствие и 2–4 уточняющих вопроса;
- персонализированная презентация сборки;
- проверка сокета, DDR4/DDR5, форм-фактора, BIOS, питания, размеров корпуса и охлаждения;
- каталог моделей с ценами-ориентирами и прямыми ссылками на карточки DNS;
- локальный RAG-lite без внешней базы данных;
- выбор модели RouterAI и ручной ввод model ID;
- сохранение API-ключа и модели после перезагрузки;
- три smoke-теста без расхода API-баланса.

## Импорт в Replit

1. В Replit выберите **Create App → Import from GitHub**.
2. Выберите репозиторий `Dimar4713/dns-pc-ai-consultant`.
3. Основная ветка: `dns-pc-ai-consultant`.
4. Replit установит зависимости командой `npm install`.
5. Запустите проект кнопкой **Run** или командой `npm start`.
6. В интерфейсе нажмите ⚙, введите API-ключ RouterAI и выберите модель.

API-ключ не добавляйте в GitHub. Для учебного задания он хранится только в `localStorage` браузера. Для публичного приложения предпочтительны Replit Secrets.

## Локальный запуск

```bash
npm install
npm start
```

По умолчанию сервер использует переменную `PORT` или порт `3000`.

## Проверка

```bash
npm test
```

Тест запускает локальный mock RouterAI и проверяет три сценария:

1. игровой ПК Full HD;
2. рабочая станция для монтажа 4K;
3. компактный офисный ПК без дискретной видеокарты.

## Структура

```text
server.js                 сервер Express и запросы RouterAI
public/                   интерфейс чата
data/knowledge-base-*.md  база знаний, совместимость, модели, цены и ссылки DNS
prompts/system-prompt.md  системная инструкция консультанта
docs/REPLIT_TZ.md         техническое задание
docs/REPLIT_MASTER_PROMPT.md  промпт для Replit Agent
docs/MODEL_SELECTION.md   выбор моделей RouterAI по цене/качеству
docs/TEST_DIALOGS.md      протокол трёх тестовых диалогов
scripts/smoke-test.js     автоматическая проверка
```

База разделена на пять Markdown-файлов для удобства сопровождения. Сервер автоматически находит `data/knowledge-base-*.md`, сортирует их и объединяет при запуске.

## Ограничения

Цены приведены как ориентировочный срез на **18 июля 2026 года** и зависят от региона, акции и наличия. Консультант не должен выдумывать цену, наличие, версию BIOS или физическую совместимость, если параметр отсутствует в базе. Перед покупкой необходимо открыть карточки DNS и проверить данные для своего города.
