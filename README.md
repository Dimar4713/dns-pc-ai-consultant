# DNS PC AI Consultant

[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](LICENSE)

Пилотный AI-консультант по подбору совместимого компьютера и полного рабочего места на основе товарного среза DNS.ru.

Репозиторий демонстрирует архитектуру прикладного AI-консультанта: диалоговый интерфейс, серверную интеграцию с OpenAI-совместимым API RouterAI.ru, локальный RAG-lite, формальные правила совместимости и разделение доступа на публичного пользователя и администратора.

## Возможности

- публичный чат без регистрации и без ввода API-ключа;
- API-ключ RouterAI хранится только на сервере;
- защищённая административная панель по адресу `/admin`;
- режимы доступа `PUBLIC`, `INVITE_ONLY` и `DISABLED`;
- лимиты сообщений на сессию, IP и весь сервис;
- метрики использования и ошибок модели;
- настройка модели, температуры, длины ответа и приветствия;
- перезагрузка базы знаний без перезапуска приложения;
- самодиагностика конфигурации;
- приветствие и уточняющие вопросы;
- персонализированная презентация сборки;
- проверка сокета, DDR4/DDR5, форм-фактора, BIOS, питания, размеров корпуса и охлаждения;
- подбор монитора, периферии, Wi‑Fi/Bluetooth, звука и защиты питания;
- локальный RAG-lite без внешней векторной базы;
- категорийная маршрутизация запросов;
- история диалогов в браузере и печать результата в PDF;
- smoke-тесты без расхода реального API-баланса.

## Режимы доступа

### Публичный пользователь

Пользователь открывает главную страницу и сразу работает с консультантом. Он не видит API-ключ, системный промпт, модель и внутренние настройки.

### Администратор

Административная панель доступна по адресу:

```text
https://ваш-домен/admin
```

После входа администратор может:

- включать и отключать публичную демонстрацию;
- выбирать модель RouterAI;
- менять лимиты и параметры генерации;
- просматривать оперативные метрики;
- запускать самодиагностику;
- перезагружать базу знаний.

Административная сессия хранится в подписанной `HttpOnly` cookie с атрибутами `SameSite=Strict` и `Secure` при работе по HTTPS.

## Настройка переменных окружения

Скопируйте перечень переменных из [`.env.example`](.env.example) в Secrets или Variables выбранного хостинга.

Обязательные переменные:

```env
ROUTERAI_API_KEY=...
ROUTERAI_MODEL=deepseek/deepseek-v4-pro
ADMIN_EMAIL=dimamarareskul@gmail.com
ADMIN_PASSWORD_HASH=...
SESSION_SECRET=...
PUBLIC_MODE=PUBLIC
```

API-ключ, пароль и `SESSION_SECRET` нельзя добавлять в GitHub.

### Создание хеша пароля администратора

```bash
npm run hash-password -- "ваш сложный пароль длиной не менее 12 символов"
```

Полученную строку целиком сохраните в переменной `ADMIN_PASSWORD_HASH`.

Для `SESSION_SECRET` используйте случайную строку длиной не менее 32 символов.

## Публичный режим по приглашению

Для адресной демонстрации потенциальному заказчику установите:

```env
PUBLIC_MODE=INVITE_ONLY
DEMO_INVITE_CODE=случайный-код
```

После этого можно передать персональную ссылку:

```text
https://ваш-домен/?code=случайный-код
```

Код удаляется из адресной строки после открытия и сохраняется только в `sessionStorage` текущей вкладки.

## Развёртывание

Проект можно развернуть в Replit, Timeweb Cloud App Platform, Amvera или на обычном Node.js-хостинге.

Для публичной презентации рекомендуется:

1. подключить репозиторий к хостингу;
2. выбрать ветку `dns-pc-ai-consultant`;
3. установить Node.js 20 или новее;
4. задать переменные окружения;
5. использовать команду запуска `npm start`;
6. подключить собственный домен и HTTPS;
7. открыть `/admin` и выполнить самодиагностику.

## Локальный запуск

```bash
npm install
npm start
```

Без `ROUTERAI_API_KEY` приложение запустится, но публичный чат будет отмечен как не настроенный.

## Проверка

```bash
npm test
```

Тест запускает локальный mock RouterAI и проверяет:

- семь сценариев подбора;
- использование серверного API-ключа;
- категорийную RAG-маршрутизацию;
- вход администратора;
- подписанную административную сессию;
- самодиагностику конфигурации.

## Ограничения пилота

Это репрезентативный пилотный срез, а не полная зеркальная копия DNS. Цены и наличие зависят от региона, акции и даты. Консультант не должен выдумывать цену, наличие, версию BIOS, физическую совместимость или комплектность кабелей.

Лимиты и метрики текущей версии хранятся в памяти одного экземпляра Node.js и сбрасываются после перезапуска. Для горизонтального масштабирования промышленной версии их следует перенести в Redis или другую централизованную систему хранения.

Настройки, изменённые через административную панель, действуют до перезапуска приложения. Постоянные значения задаются переменными окружения хостинга.
